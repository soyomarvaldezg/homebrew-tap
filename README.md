# Homebrew Tap

Personal Homebrew casks and formulae by [Omar Valdez](https://github.com/soyomarvaldezg).

## Available

### mocksmith

Generate realistic fake data for testing, demos, and data engineering pipelines.

```bash
brew install --cask soyomarvaldezg/tap/mocksmith
```

Or add the tap first:

```bash
brew tap soyomarvaldezg/tap
brew install --cask mocksmith
```

More tools will be added here as they are released.
